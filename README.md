# 💳 Credit Card Data Analysis Dashboard

This Power BI project presents a comprehensive and interactive dashboard built on credit card transaction and customer data sourced from a SQL database. It provides visual insights into customer spending patterns, revenue streams, and demographic behavior across multiple business dimensions.

---

## 📊 Key Features

- **Quarterly Revenue Trends**: Monitor revenue and transaction volume across Q1–Q4.
- **Expenditure Breakdown**: Revenue analyzed by categories such as Bills, Grocery, Fuel, Entertainment, and Travel.
- **Demographic Insights**:
  - Education Level
  - Income Type
  - Age Group
  - Marital Status
  - Job Type
  - State-wise Revenue Distribution
- **Card Category Analysis**: Revenue, total transaction amount, and interest earned across Blue, Silver, Gold, and Platinum cards.
- **Transaction Mode Analysis**: Revenue categorized by Swipe, Chip, and Online payments.

---

## 🛠️ Tools & Technologies Used

- **Power BI Desktop**
- **SQL Database (Source Data)**
- **Data Modeling & DAX**
- **Interactive Visualizations**

---

## 📌 Use Cases

- Credit card business intelligence for banks and financial institutions
- Customer segmentation and behavioral targeting
- Financial performance reporting and strategic decision making
